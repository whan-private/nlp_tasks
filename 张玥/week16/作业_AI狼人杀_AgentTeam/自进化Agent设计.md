# 自进化 Agent 设计

## 1. 为什么做自进化

狼人杀是一个信息不对称博弈游戏。单局表现并不能代表 Agent 的真实能力，因为角色、发言顺序和投票都会影响结果。

自进化的目标是让 Agent 不只是“跑完一局”，而是能够：

```text
对局 -> 复盘 -> 经验沉淀 -> 下一局调整策略
```

## 2. 本版自进化方式

本作业不让 Agent 直接修改代码，而是采用更安全的经验记忆方式。

每局结束后，Evaluator 会生成角色级经验：

- 本角色是否获胜。
- 本角色的行动是否有效。
- 是否需要更积极发言。
- 是否需要更重视投票历史。
- 是否需要隐藏身份或加强协作。

经验写入：

```text
memory/role_experience.json
```

## 3. 经验如何影响下一局

下一局 Agent 初始化时会读取经验。

示例：

- 狼人连续失败：下一局更积极引导投票，优先攻击公开怀疑狼人的玩家。
- 预言家失败：下一局更倾向于公开关键查验结果。
- 女巫失败：下一局更谨慎使用毒药，优先保留解药。
- 村民失败：下一局更重视发言中自相矛盾的玩家。

## 4. 为什么不直接让 Agent 改代码

作业题里提到“读懂自己 -> 修改自己 -> 运行自己”的通用 Agent 方向，但本次你选择的是自进化 Agent。

直接改代码风险较高：

- 容易破坏游戏规则。
- 容易生成不可运行代码。
- 不利于稳定测试。

因此本版采用“策略记忆自进化”，既能体现学习能力，又能保证作业可运行。

## 5. 后续进阶方向

如果继续扩展，可以做：

- 不同模型 Agent 同台竞技。
- 胜率排行榜 Leaderboard。
- 角色级策略版本管理。
- 每局自动生成复盘报告。
- 使用 LLM 总结更高质量的经验。
- 将经验转成 Prompt 片段注入角色 Agent。
