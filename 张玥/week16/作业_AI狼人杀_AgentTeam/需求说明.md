# AI 狼人杀 Agent Team 需求说明

## 1. 作业目标

构建一个可以自主完成狼人杀对局的多智能体系统。每个玩家由一个 Agent 扮演，不同角色拥有不同目标、信息边界和行动空间。

核心要求：

- 支持完整狼人杀对局流程。
- 支持狼人、预言家、女巫、猎人、村民等角色。
- 保证信息隔离。
- 输出结构化日志，方便复盘。
- 实现自进化 Agent：对局结束后分析经验，并影响下一局策略。

## 2. 默认对局配置

本作业默认使用 6 人局：

```text
2 狼人 + 1 预言家 + 1 女巫 + 1 猎人 + 1 村民
```

阵营：

- 狼人阵营：狼人。
- 好人阵营：预言家、女巫、猎人、村民。

胜负规则：

- 所有狼人死亡：好人胜利。
- 狼人数量大于等于好人数量：狼人胜利。
- 达到最大天数仍未结束：根据存活阵营人数裁决，人数相等或狼人更多则狼人胜，否则好人胜。

## 3. 信息隔离要求

狼人：

- 知道自己的角色。
- 知道狼人队友。
- 不知道预言家、女巫、猎人、村民的真实身份。

预言家：

- 知道自己的角色。
- 每晚可以查验一名玩家阵营。
- 只能知道自己的查验结果。

女巫：

- 知道自己的角色。
- 知道当晚被狼人击杀的人。
- 拥有一次解药和一次毒药。

猎人：

- 知道自己的角色。
- 死亡时可以开枪带走一名玩家。

村民：

- 只知道公开发言、投票和死亡信息。

## 4. 行动空间

夜晚阶段：

- 狼人选择击杀目标。
- 预言家选择查验目标。
- 女巫选择是否救人或毒人。

白天阶段：

- 所有存活玩家依次发言。
- 所有存活玩家投票。
- 得票最高玩家出局。

特殊行动：

- 猎人死亡后可以带走一名玩家。

## 5. 结构化日志要求

每局游戏需要输出：

- 游戏 ID
- 角色分配
- 玩家风格
- 每晚行动
- 每天发言
- 每天投票
- 死亡顺序
- 胜利阵营
- 复盘摘要

日志保存到：

```text
logs/game_*.json
```

## 6. 自进化目标

每局结束后，系统会根据结果生成经验：

- 哪个阵营胜利。
- 哪些角色策略有效。
- 哪些角色需要改进。
- 下一局该角色应该更激进、更谨慎还是更重视历史发言。

经验保存到：

```text
memory/role_experience.json
```

下一局 Agent 会读取这些经验，在发言和投票时体现策略变化。

## 7. 本版边界

本作业优先保证本地可运行，因此默认使用规则 Agent，不强依赖大模型。

LLM 决策作为扩展点保留，后续可以把规则策略替换成模型调用。
