## 2. 单局演示测试

```powershell
D:\AI_study_env\miniconda3\envs\py312\python.exe main_demo.py
```

预期：

- 游戏能从夜晚开始推进。
- 能完成发言、投票、死亡结算。
- 最终输出胜利阵营。
- `logs/game_*.json` 被写入。

## 3. 信息隔离测试

测试点：

- 狼人 view 中能看到队友。
- 村民 view 中不能看到任何隐藏身份。
- 预言家只能看到已查验结果。
- 女巫能看到当晚被击杀玩家，但不知道所有角色身份。

## 4. 夜晚流程测试

测试点：

- 狼人可以选择击杀目标。
- 预言家可以查验一名玩家。
- 女巫可以使用解药或毒药。
- 夜晚死亡记录能正确写入日志。

## 5. 白天流程测试

测试点：

- 存活玩家会依次发言。
- 存活玩家会投票。
- 得票最高玩家出局。
- 死亡玩家不会继续发言和投票。

## 6. 胜负裁决测试

测试点：

- 狼人全灭时好人胜利。
- 狼人数量大于等于好人数量时狼人胜利。

## 7. 自进化测试

测试命令：

```powershell
D:\AI_study_env\miniconda3\envs\py312\python.exe run_self_evolution_demo.py
```

预期：

- 连续运行多局。
- 生成 `memory/role_experience.json`。
- 生成 `logs/evolution_*.json`。
- 下一局 Agent 能读取上一局经验。

## 8. FastAPI 测试

测试点：

- `GET /` 能返回观战页面。
- `POST /games` 能创建对局。
- `POST /games/{game_id}/run` 能运行对局。
- `GET /games/{game_id}` 能获取结构化日志。
- `POST /tournaments/self-evolution` 能运行多局自进化。

## 9. 前端观战页面测试

启动命令：

```powershell
D:\AI_study_env\miniconda3\envs\py312\python.exe -m uvicorn werewolf_game.api:app --reload
```

浏览器访问：

```text
http://127.0.0.1:8000/
```

测试点：

- 页面能输入随机种子并创建对局。
- 点击“运行完整对局”后，能看到玩家卡片、胜利阵营、复盘摘要。
- 时间线能展示夜晚行动、白天发言、投票和死亡记录。
- 点击“运行 3 局自进化”后，能看到每局结果和角色经验。
- 页面仅使用原生 `fetch` 调用 FastAPI，不需要 Node.js 或前端构建工具。
