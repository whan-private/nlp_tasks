# AI 狼人杀 Agent Team 架构设计

## 1. 总体架构

本项目可以拆成五层：

```text
GameEngine 对局引擎
  -> RoleAgent 角色智能体
  -> Information Isolation 信息隔离
  -> Evaluator 复盘评测
  -> Memory 自进化经验
```

## 2. 模块说明

### `schemas.py`

定义核心数据结构：

- 玩家
- 角色
- 阵营
- 发言记录
- 投票记录
- 夜晚行动
- 死亡记录
- 游戏记录

这些结构用于保证日志可观测、可测试、可复盘。

### `roles.py`

定义每个角色的目标和可见信息：

- 狼人：隐藏身份，配合队友击杀好人。
- 预言家：查验身份，帮助好人找狼。
- 女巫：使用解药和毒药影响夜晚结果。
- 猎人：死亡后开枪带走可疑目标。
- 村民：根据公开信息推理和投票。

### `agents.py`

实现角色 Agent 的决策逻辑。

本版默认是规则 Agent：

- 根据角色目标行动。
- 根据公开发言和历史投票做简单判断。
- 读取 `memory/role_experience.json` 调整策略。

后续可扩展为 LLM Agent：

```text
角色视角信息 -> Prompt -> LLM -> 结构化动作
```

### `engine.py`

实现完整对局流转：

```text
角色分配
  -> 夜晚行动
  -> 死亡结算
  -> 白天发言
  -> 白天投票
  -> 放逐结算
  -> 胜负判断
```

### `memory.py`

负责保存和读取角色经验。

经验包括：

- 角色总局数
- 胜利次数
- 失败次数
- 策略提示
- 最近一次复盘建议

### `evaluator.py`

负责对单局结果进行复盘：

- 分析胜负。
- 统计投票命中情况。
- 给不同角色生成经验建议。
- 写入 memory。

### `api.py`

提供轻量 FastAPI 接口：

- 创建对局。
- 运行对局。
- 获取日志。
- 运行多局自进化实验。

## 3. 信息隔离设计

关键原则：

> Engine 知道全局真相，但 Agent 只能收到自己的 View。

例如狼人 Agent 的 view 中包含：

- 自己身份
- 狼人队友
- 存活玩家
- 公开发言和死亡信息

但不包含：

- 谁是预言家
- 谁是女巫
- 谁是猎人

预言家只能看到自己的查验结果，普通村民只能看到公开信息。

## 4. 自进化设计

自进化链路：

```text
运行一局
  -> 生成结构化日志
  -> Evaluator 复盘
  -> 写入角色经验
  -> 下一局 Agent 读取经验
  -> 调整发言和投票倾向
```

本版是轻量自进化，不修改代码本身，而是修改角色记忆和策略偏好。

这更适合作业演示，也更安全可控。
