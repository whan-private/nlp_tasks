# 狼人杀多Agent自演化系统设计文档

## 1. 概述

本项目在原有狼人杀多Agent协作框架基础上，增加了自演化能力，实现了“通用Agent → 狼人杀多角色Agent”的自适应演化。核心思想是：Agent能够“读懂自己（评估代码/表现）→ 修改自己（优化提示词/策略）→ 运行自己（重新加载并应用改进）”，形成一个自我改进的闭环系统。

## 2. 系统架构

原系统已包含以下核心组件：
- **游戏引擎**：控制流程、执行规则、判定胜负
- **玩家Agent**：基于LLM的角色代理，接收游戏状态，输出决策
- **角色系统**：定义狼人、预言家、女巫、猎人、村民等角色的能力与阵营
- **经验记忆**：存储过往游戏总结，支持跨游戏经验共享
- **总结代理**：游戏结束后为每个玩家生成表现总结

新增的自演化组件：
- **演化代理 (EvolutionAgent)**：分析历史经验，生成优化后的角色提示词
- **提示词仓库 (agent/prompts/)**：存储各角色类型的优化提示词
- **自演化引擎**：在游戏结束后自动触发演化流程

## 3. 自演化流程

### 3.1 演化触发
游戏结束后，系统依次执行：
1. **总结经验**：为每个玩家生成结构化总结（summary, strategies, mistakes, lessons）
2. **保存经验**：将总结存储到角色对应的经验文件中
3. **演化分析**：对每个角色类型，加载最近5条经验，分析常见错误和有效策略
4. **提示词优化**：使用LLM生成改进后的角色提示词，融入学到的最佳实践
5. **提示词保存**：将优化后的提示词保存到 `agent/prompts/{role_type}.txt`

### 3.2 提示词应用
下一次创建同类型角色Agent时：
1. Agent初始化时检查是否存在优化提示词
2. 如果存在，优先使用优化提示词作为基础指令
3. 在优化提示词中动态替换变量（角色名、阵营、玩家ID等）
4. 添加上次演化后的经验总结
5. 确保包含必要的输出格式要求

### 3.3 迭代演化
随着游戏局数增加：
- 经验库不断丰富，演化分析越来越精准
- 提示词持续优化，融入更多实战策略
- Agent的决策质量逐步提升，形成自我强化飞轮

## 4. 关键技术实现

### 4.1 演化代理 (EvolutionAgent)
- **输入**：角色类型 + 该角色的历史经验列表
- **处理**：分析胜率、常见错误、有效策略，构建演化提示词
- **输出**：优化后的角色提示词，包含角色介绍、游戏规则、策略指导、常见陷阱警告

### 4.2 提示词模板系统
- 支持变量替换：`{role_name}`, `{camp_desc}`, `{player_id}`, `{private_context}`
- 支持经验章节插入：`{experience_section}`
- 向后兼容：无优化提示词时使用默认模板

### 4.3 经验分析算法
- 胜率计算：`wins / total_games`
- 错误模式提取：从mistakes字段提取高频错误
- 策略有效性分析：从strategies字段提取成功策略
- 最近优先：优先分析最近5条经验，反映最新学习成果

## 6. 演化效果评估

### 6.1 评估指标
- **胜率变化**：同一角色类型在不同演化阶段的胜率对比
- **错误减少**：常见错误在演化后是否减少
- **策略丰富度**：优化提示词中是否包含更多有效策略
- **游戏时长**：是否因决策优化而缩短游戏进程

### 6.2 可视化监控
建议后续增加：
- 演化历史追踪：记录每次提示词变化
- 性能对比图表：展示演化前后胜率变化
- 策略演进图谱：可视化策略的迭代优化过程

## 7. 进阶方向

### 7.1 多维度演化
当前系统仅优化角色提示词，未来可扩展：
- **决策风格演化**：根据角色类型动态调整决策风格参数
- **策略库构建**：建立可复用的策略模块库
- **元学习能力**：让Agent学习如何更好地学习

### 7.2 对抗性演化
- **红蓝对抗**：好人阵营和狼人阵营分别演化，形成博弈平衡
- **策略抵消**：当某种策略过于强大时，对手演化出克制策略

### 7.3 人类反馈集成
- **人类评估**：引入人类玩家对Agent表现评分
- **示范学习**：从人类高手对局中学习策略
- **偏好对齐**：确保Agent行为符合人类道德和游戏礼仪

## 8. 使用指南

### 8.1 启动演化
```python
from agent.evolution_agent import evolve_all_roles

# 自动演化所有角色
results = await evolve_all_roles()
```

### 8.2 手动触发
游戏引擎在`_run_summaries()`后可添加：
```python
# 在游戏结束后触发演化
from agent.evolution_agent import evolve_all_roles
await evolve_all_roles()
```

### 8.3 监控演化
检查`agent/prompts/`目录下的提示词文件，观察其内容变化。

## 9. 总结

本自演化系统实现了狼人杀Agent从通用到专精的自我进化，核心创新点包括：
1. **闭环学习**：对局 → 总结 → 分析 → 优化 → 再对局
2. **提示词优化**：动态更新角色指令，融入实战经验
3. **渐进改进**：基于历史数据的持续迭代优化
4. **可观测性**：所有演化过程均有结构化记录

该系统为多Agent协作框架赋予了自我改进能力，为后续的对抗演化、元学习等进阶方向奠定了基础。
